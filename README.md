## Maintain this portfolio

Edit `projects.json` to update project descriptions, categories, technologies, links and image captions. Add reviewed captures under `assets/screenshots/`. Keep private source code and real operational data outside this repository.

The site is plain HTML, CSS and JavaScript, with no build step, API keys, analytics or third-party runtime dependencies. Serve the folder with `python -m http.server 8000` for local preview. GitHub Pages publishes the root of `main`.
